## ✨ TinyPix چیه؟

TinyPix یک ابزار **فشرده‌سازی تصویر داخل مرورگر**ه؛ یعنی عکس‌ها برای فشرده‌سازی به سرور آپلود نمی‌شن.

🎯 هدف پروژه: **حجم کمتر، کنترل بیشتر، ظاهر خفن‌تر.**

### 🫧 طراحی Liquid Glass
رابط کاربری با الهام از ظاهر شیشه‌ای مدرن ساخته شده و شامل:
- ✨ موشن و انیمیشن‌های نرم
- 🪟 کارت‌های شیشه‌ای و نورپردازی
- 🌈 Aurora و افکت‌های شناور
- 📱 طراحی واکنش‌گرا برای موبایل و PC
- ♿ پشتیبانی از کاهش حرکت

## 🔐 حریم خصوصی

**تصویرت جایی آپلود نمی‌شه.**

پردازش تصویر با APIهای خود مرورگر انجام می‌شه و TinyPix برای فشرده‌سازی به بک‌اند نیاز نداره.
